# 🎬 QuickShow – Movie Ticket Booking WebApp  

QuickShow is a **full-stack movie ticket booking application** where users can explore movies, check available shows, book seats, and manage their bookings. It includes a **secure admin panel** to manage movies, shows, and bookings.  

Built using **React (Vite)** on the frontend and **Node.js + Express** on the backend with **MongoDB** for data storage and **Clerk** for authentication.  

---

## 🚀 Features  

### 👤 User Features  
- Browse movies with posters, trailers, and descriptions  
- Select show timings and book seats with a visual layout  
- View and manage booking history  
- Authentication with Clerk (Login/Signup)  
- Add movies to favorites  

### 🛠 Admin Features  
- Admin dashboard with analytics  
- Add, update, and delete movies  
- Create and manage show timings  
- View and manage user bookings  

---

## 🏗 Tech Stack  

### Frontend  
- ⚡ React (Vite)  
- 🎨 TailwindCSS  
- 📊 Recharts (for analytics)  
- 🔑 Clerk (Authentication)  

### Backend  
- 🚀 Node.js + Express.js  
- 🛢 MongoDB (Mongoose ODM)  
- 📧 NodeMailer (Email Notifications)  
- 💳 Stripe (Payment Integration with Webhooks)  
- 🔐 JWT-based Authorization
